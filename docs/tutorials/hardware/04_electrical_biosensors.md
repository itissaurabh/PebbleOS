# Section 4: Electrical Biosensors

## Introduction

Electrical biosensors measure bioelectrical signals generated by the body, including cardiac activity (ECG), electrodermal activity (EDA/GSR), and body composition through bioimpedance analysis (BIA). These sensors require careful analog design to extract microvolt-level signals.

## Electrocardiography (ECG)

### Physiological Basis

ECG measures the electrical activity of the heart from the body surface. The cardiac cycle produces distinct waveforms:

```
        R
        │\
        │ \
        │  \
    P  /    \     T
   /\ /      \   /\
──/  \/       \_/  \──────────
      Q    S

P wave:  Atrial depolarization
QRS:     Ventricular depolarization
T wave:  Ventricular repolarization
```

### Signal Characteristics

| Parameter | Typical Value | Notes |
|-----------|---------------|-------|
| Amplitude | 0.5-3 mV | Lead-dependent |
| Frequency content | 0.05-150 Hz | Diagnostic quality |
| Wearable bandwidth | 0.5-40 Hz | Acceptable for HR/HRV |
| Noise floor target | <10 μVrms | For clean detection |

### Wearable ECG Configurations

| Configuration | Electrodes | Signal | Use Case |
|---------------|------------|--------|----------|
| Single-lead (Lead I) | Both hands | Limb-to-limb | On-demand spot check |
| Single-lead (chest) | Chest patch | Local cardiac | Continuous monitoring |
| Watch-based | Back + side button | Wrist-to-finger | Consumer devices |

### Electrode Design

#### Electrode Materials

| Material | Contact Type | Pros | Cons |
|----------|--------------|------|------|
| Ag/AgCl | Wet (gel) | Gold standard, low noise | Gel dries, skin irritation |
| Stainless steel | Dry | Durable, no consumables | Higher impedance, motion artifact |
| Ti/TiN | Dry | Biocompatible | Higher cost |
| Conductive polymer | Dry | Flexible, conformable | Degradation over time |
| Carbon/graphene | Dry | Emerging technology | Research stage |

#### Electrode-Skin Interface

```
         Electrode
            │
┌───────────┴───────────┐
│      Metal Contact    │
├───────────────────────┤
│    Double Layer       │  ◀── Electrochemical interface
├───────────────────────┤      (half-cell potential)
│    Stratum Corneum    │  ◀── High impedance layer
├───────────────────────┤
│    Epidermis          │
├───────────────────────┤
│    Dermis + Sweat     │  ◀── Conductive layer
└───────────────────────┘

Typical impedance: 10 kΩ - 1 MΩ @ 10 Hz (dry electrodes)
```

#### Key Specifications

| Parameter | Requirement | Purpose |
|-----------|-------------|---------|
| Input impedance | >10 MΩ | Handle dry electrode impedance |
| CMRR | >80 dB | Reject 50/60 Hz interference |
| Input bias current | <1 nA | Minimize DC offset |
| Input-referred noise | <10 μVrms | Clean signal |
| Gain | 100-1000x | Amplify mV to V range |

## Electrodermal Activity (EDA/GSR)

### Physiological Basis

EDA measures skin conductance changes due to sweat gland activity, controlled by the sympathetic nervous system. It's used for stress detection and emotional response monitoring.

### Signal Characteristics

| Parameter | Typical Value |
|-----------|---------------|
| Skin conductance | 1-100 μS |
| Tonic (SCL) | Slow baseline |
| Phasic (SCR) | Fast responses (1-3s) |
| Frequency content | DC - 5 Hz |

### Measurement Methods

#### Constant Voltage Method
```
         Vexcite
            │
            R_measure
            │
   ┌────────┴────────┐
   │                 │
   ●                 ●
 Electrode 1    Electrode 2
   │                 │
   └──────┬──────────┘
          │
        Skin (Rskin varies)
          │
         GND

Rskin = Vexcite / Imeasure - R_measure
```

#### Constant Current Method
```
         Iexcite (constant)
            │
            ▼
   ┌────────┴────────┐
   │                 │
   ●                 ●
 Electrode 1    Electrode 2
   │                 │
   └──────┬──────────┘
          │
        Skin
          │
         GND

Vskin = Iexcite × Rskin
```

### Design Considerations

| Factor | Consideration |
|--------|---------------|
| Excitation | AC preferred (reduces polarization) |
| Frequency | 10-100 Hz typical |
| Current | <10 μA for comfort |
| Electrode | Stainless steel or Ag/AgCl |
| Location | Fingers, wrist (palmar side) |

## Bioimpedance Analysis (BIA)

### Principle

BIA measures the impedance of body tissue by injecting a small AC current and measuring the resulting voltage. Different tissues have characteristic impedance:

| Tissue | Resistivity (Ω·cm) |
|--------|-------------------|
| Blood | 150 |
| Muscle | 300-1600 |
| Fat | 2000-2500 |
| Bone | 16000+ |

### Applications in Wearables

| Application | Frequency | Measurement |
|-------------|-----------|-------------|
| Body composition | 50 kHz | Fat vs. lean mass |
| Hydration | Multi-frequency | ICW/ECW ratio |
| Respiration | 50-100 kHz | Thoracic impedance |
| Pulse detection | 50 kHz | Impedance plethysmography |

### Multi-Frequency BIA

Different frequencies probe different compartments:

| Frequency | Behavior |
|-----------|----------|
| <5 kHz | Current flows around cells (ECW only) |
| 50 kHz | Standard measurement frequency |
| >100 kHz | Current penetrates cell membranes |
| Sweep | Cole-Cole model fitting |

## Common Design Challenges

### Interference Sources

| Source | Frequency | Mitigation |
|--------|-----------|------------|
| Power line | 50/60 Hz | Notch filter, shielding |
| EMI | Variable | Filtering, layout |
| Motion | DC-10 Hz | High-pass filter, algorithm |
| Electrode noise | Broadband | Low-noise design |

### Right Leg Drive (RLD)

Active ground technique to improve CMRR:

```
                    ┌─────────────┐
   Common-mode ────▶│   Inverting │──────▶ RL Electrode
   signal           │   Amplifier │
                    └─────────────┘

Feeds back inverted common-mode signal to reduce interference
```

### Lead-Off Detection

Detecting when electrodes lose skin contact:

| Method | Description |
|--------|-------------|
| DC current | Inject small DC, detect open circuit |
| AC current | Measure impedance at high frequency |
| Comparator | Threshold on signal amplitude |

## Signal Processing

### ECG Processing Pipeline

```
Raw ADC ──▶ HPF ──▶ Notch ──▶ LPF ──▶ R-peak ──▶ HR/HRV
            │       Filter    │      Detection
            │       50/60Hz   │
            ▼                 ▼
        Remove            Remove
        baseline          noise
        wander
```

### Key Algorithms

| Algorithm | Purpose | Method |
|-----------|---------|--------|
| Pan-Tompkins | R-peak detection | Derivative, squaring, integration |
| Adaptive filter | Motion removal | LMS with accelerometer |
| Wavelet denoising | Noise reduction | Multi-resolution analysis |
| HRV analysis | Autonomic function | Time/frequency domain metrics |

## Power Considerations

| Mode | Typical Current | Use Case |
|------|-----------------|----------|
| Continuous ECG | 100-500 μA | Medical monitoring |
| On-demand ECG | ~0 (standby) | Spot check |
| Continuous EDA | 10-50 μA | Stress tracking |
| BIA measurement | 50-200 μA | Periodic composition |

## Summary

Electrical biosensors enable advanced health monitoring:

- **ECG**: Requires careful analog design, >80 dB CMRR critical
- **EDA**: Simpler measurement, useful for stress detection
- **BIA**: Multi-frequency analysis for body composition
- **Electrodes**: Dry electrode design is key challenge for wearables
- **Integration**: Modern AFE ICs simplify implementation
